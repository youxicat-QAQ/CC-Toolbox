## 三、已知差异与注意

1. **`/api/search` 响应形态变更（新版）**：由数组改为对象 `{results, truncated, total_matched}`——网页前端已适配；如你有外部脚本调用此接口需同步修改
2. **新版首次启动约 10~20 秒**（全盘扫描工具目录），属正常；等待窗口可关闭，服务后台继续
3. **launcher.bat 与桌面图标行为相同**：第一次双击 = 启动，再次双击 = 停止；launcher.bat 多显示过程输出（排障用）
4. **venv 文件夹很大是正常的**（内含完整 Python 副本）；删掉后双击 launcher.bat 自动重建
5. 图标不刷新时：桌面 F5 → 仍不行则任务管理器重启「Windows 资源管理器」
